# Security Policy

## Reporting a Vulnerability

Please **do not** open a public issue for security problems (token handling, pairing,
backup encryption, access control, data exposure between users).

Report them privately via
[GitHub Security Advisories](https://github.com/markus7h/ai-rem/security/advisories/new)
("Report a vulnerability"). Include the affected version (`ai-rem status` shows it),
steps to reproduce and the impact you see.

You will get an answer as soon as possible. Fixes go into the next release and are
listed in `CHANGELOG.md`.

## Supported Versions

Only the latest release receives security fixes.

ai-rem installieren

Client-Setup für eine neue Maschine — ein Befehl, idempotent (mehrfach ausführen ist sicher)

macOS · Linux · WSL

bash <(curl -s __KG_URL__/setup)

Im Terminal ausführen. Aus dem Claude-Code-Prompt: dieselbe Zeile mit vorangestelltem ! (läuft in deiner Shell, der Agent führt sie nie selbst aus).

Windows (PowerShell, nativ)

irm __KG_URL__/setup.ps1 | iex

Kein WSL nötig — claude CLI nativ. Fehlt Python: winget install Python.Python.3.12, fehlt claude: irm https://claude.ai/install.ps1 | iex

SSH-Zugang einrichten (Secret-Pull)

Das Setup zieht die Tokens per ssh __SSH_HOST__ vom Server — einmal pro Maschine einrichten:

1 · Key erzeugen (alle Plattformen, Enter-Defaults sind ok)
ssh-keygen -t ed25519
2 · Host-Eintrag in ~/.ssh/config (Windows: C:\Users\<name>\.ssh\config)
Host __SSH_HOST__
    HostName __SSH_HOSTNAME__
    User __SSH_USER__
    IdentityFile ~/.ssh/id_ed25519
3 · Public-Key auf den Server — macOS/Linux/WSL:
ssh-copy-id __SSH_HOST__
   …Windows (PowerShell, kein ssh-copy-id an Bord):
type $env:USERPROFILE\.ssh\id_ed25519.pub | ssh __SSH_HOST__ "cat >> ~/.ssh/authorized_keys"
4 · Testen (muss ohne Passwort-Abfrage durchlaufen)
ssh __SSH_HOST__ true && echo OK

Ohne SSH-Zugang läuft das Setup trotzdem — dann Token manuell mitgeben: AI_REM_TOKEN=<token> bzw. $env:AI_REM_TOKEN.

Voraussetzungen

  • Pflicht: python3 + claude CLI — fehlt etwas, bricht das Setup mit plattformspezifischem Install-Hinweis ab
  • Optional (nur tools-registry): git, Node.js ≥ 18 inkl. npm
  • Secrets: per SSH vom Server gezogen (SSH-Key vorausgesetzt) — alternativ Token im Env: AI_REM_TOKEN=<token> bzw. $env:AI_REM_TOKEN
